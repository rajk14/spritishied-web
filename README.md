# SpitiShield AI | Himalayan Survival Intelligence

![SpitiShield Banner](https://d2xsxph8kpxj0f.cloudfront.net/103826472/mdZ2xjbCC9DSJokf87vqqG/hero-himalayan-peaks-2XmmXZW4efuWH525BtebW2.webp)

**SpitiShield AI** is a hybrid survival operating system designed specifically for the high-altitude, zero-signal environments of the Himalayas. It bridges cloud-based intelligence with local mountain resilience to provide offline-first medical triage, tactical terrain mapping, and adaptive AI that works when connectivity fails.

## 🏔️ Core Pillars

- **Resilient Intelligence**: 100% offline-capable brain for emergency decision-making.
- **Tactical Mapping**: High-resolution 3D terrain caching and mesh triangulation.
- **Survival OS**: A unified interface for rescue protocols, biometric monitoring, and emergency SOS.

## 🚀 Technology Stack

- **Frontend**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Vanilla CSS (Tactical Cyberpunk Aesthetic)
- **Animations**: Framer Motion + Lucide React
- **Deployment**: GitHub Pages (Live Preview)

## 🛠️ Key Features

- **Interactive System Preview**: Explore the mobile HUD through an animated gallery.
- **Tactical Auth Flow**: Experience the operator authorization sequence.
- **Briefing Video**: Full-screen video demonstration of the system in action.
- **System Documentation**: Comprehensive guides on ALPHA sync, OMEGA broadcast, and SIGMA caching.
- **API Reference**: Standardized protocols for terrain analysis and emergency triage.

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rajk14/spritishied-web.git
   ```
2. Install dependencies:
   ```bash
   pnpm install
   ```
3. Start the development server:
   ```bash
   pnpm run dev
   ```
